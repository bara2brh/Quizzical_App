# 🧠 Quizzical App

A simple trivia quiz app built with React that fetches questions from the Open Trivia Database API. Users can select answers, check their score, and play again.

## 🚀 Features

- Fetches 5 random multiple-choice questions
- Displays shuffled answers for each question
- Highlights correct and wrong answers after submission
- Score tracking
- Play again functionality
- Simple and responsive UI

---

## 🛠️ Built With

- React JS
- HTML / CSS
- JavaScript (ES6+)
- [Open Trivia DB API](https://opentdb.com/)
